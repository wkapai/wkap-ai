# Private WoW Journal Template

Recommended user-owned Markdown structure:

```text
WKAP WoW Journal/
  daily/
    2026-07-05.md
  active-trackables.md
  pending-scoreables.md
  thesis-map.md
  receipts.md
  public-verification.md
```

Each daily entry should preserve:

```yaml
daily_packet_record:
  local_journal_entry_id:
  prepared_at:
  packet_spec_version: v0.1
  skill_version: v0.1
  private_status: prepared_private
  submission_status: not_submitted
  receipt_status: no_receipt
  public_status: not_public
  public_url: null
  receipt_id: null
  packet_id: null
```

Track:

- prepared packets
- rejected packets
- no-reply days
- active trackables
- pending scoreable signals
- thesis children
- status updates
- receipt checks
- public page verification
